# 訪問管理アプリ

飛び込み営業・訪問先管理用のPWAアプリです。

## 概要

このアプリは、訪問先の場所・住所・名前・性別・タグ・メモ・訪問履歴・不在履歴を保存し、再訪問やフォローをしやすくするための個人用PWAです。

iPhone Safariでホーム画面に追加して使うことを重視しています。

## 主な機能

- 訪問先の登録・編集
- 場所・住所・一覧表示名・場所メモの保存
- 名前・性別・メモの保存
- 最終訪問日と会えた時間帯の保存
- 訪問履歴の追加・編集・削除
- 不在履歴の追加・編集・削除
- タグ管理
- タグフィルター
- キーワード検索
- スワイプ削除
- ゴミ箱復元
- 現在地から住所・座標を取得
- 地図ピッカーから座標を保存
- Google Maps起動
- JSONバックアップ
- JSON復元
- PWAホーム画面追加

## データ保存

- メインストレージ：localStorage
- 起動後スナップショット：IndexedDB
- バックアップ：JSONエクスポート

主なlocalStorageキー:

- `vm_visits`
- `vm_trash`
- `vm_tags`
- `vm_backup_date`
- `vm_version`
- `vm_last_trash_purge`

既存のlocalStorageデータは、同じドメイン・同じパスで開く限り基本的に残ります。

## データ保護方針

このプロジェクトでは、次の変更を原則禁止します。

- `vm_visits` のキー名変更
- `vm_trash` のキー名変更
- `vm_tags` のキー名変更
- localStorageの初期化
- 保存済み訪問データの破壊的な形式変更
- JSONバックアップ形式の破壊的変更

## 起動高速化・PWA更新改善版 20260709-update1

データ件数が増えた時のPWA起動白画面を軽減するため、以下を導入しています。

- 起動直後のIndexedDBスナップショットを遅延実行
- 起動直後のバックアップ通知更新を遅延実行
- ゴミ箱30日削除チェックを1日1回だけ実行
- 訪問一覧の初回描画を50件に制限
- `さらに表示` ボタンで50件ずつ追加表示
- 起動後に `version.json` を確認し、新版があれば更新通知を表示
- 「更新して再起動」ボタンでService Worker更新とバージョン付き再読み込みを実行
- 設定画面の「アプリを更新」は保険として残す
- localStorageの既存キーと保存形式は変更なし
- 既存データを削除・移行・初期化しない方針を維持

## 反映手順

1. ZIPを解凍する
2. GitHubリポジトリのルートに中身をそのままアップロードする
3. 既存ファイルは上書きする
4. GitHub上に次の不要ファイルが残っている場合は削除する
   - `INDEX_VERSION_PATCH.txt`
   - `INDEX_HTML_VERSION_PATCH.md`
   - `README_UPLOAD.txt`
   - `UPLOAD_AND_REPAIR_INSTRUCTIONS.md`
5. GitHub ActionsのDeployが完了するまで待つ
6. Safariで公開URLを `?v=20260709-update1` 付きで開く
7. 画面に「最新版があります」が表示された場合は「更新して再起動」を押す
8. 表示されない場合は設定 → アプリを更新を押す
9. それでも古い表示が残る場合のみPWAを閉じて開き直す

## 修正時の注意

- 既存データを消さない
- localStorageキーを変えない
- iPhone Safariで動作確認する
- Service Workerの更新事故に注意する
- コードを変更した場合はMarkdownも更新する
- 大きなファイルをGitHubコネクタ経由だけで取得して修正しない
- 今後はGitHubからリポジトリ一式ZIPをダウンロードしてから修正する

## 住所手入力時のGoogleマップ連携

- 現在地または地図から取得した有効な座標がある場合は、座標を優先してGoogleマップを開きます。
- 住所を手入力した場合は座標をクリアし、入力された住所文字列をそのままGoogleマップへ渡します。
- `岸谷4-4-4` のような短縮住所はGoogleマップ側の検索・推測に任せます。
- 空欄座標および誤って保存された `0,0` は有効な座標として扱いません。

## iPhoneでの外部地図・バックアップ保存

- Googleマップは新しい一時Safari画面を作らず、現在のPWA画面から起動します。
- Googleマップから戻った際に、空のブラウザ画面が残る現象を抑えます。
- iPhoneではバックアップJSONをiOS共有シートから保存します。
- 共有シートの「ファイルに保存」からiCloud DriveまたはこのiPhone内を選択できます。
- ファイル共有非対応環境では従来のダウンロード方式へ切り替えます。
- 共有をキャンセルした場合はバックアップ実施日を更新しません。
