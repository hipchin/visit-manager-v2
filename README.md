# 訪問管理アプリ

飛び込み営業・訪問先管理用のPWAアプリです。

## 概要

このアプリは、訪問先の場所・住所・名前・性別・タグ・メモ・訪問履歴・不在履歴を保存し、再訪問やフォローをしやすくするための個人用PWAです。

iPhone Safariでホーム画面に追加して使うことを重視しています。

## 主な機能

- 訪問先の登録・編集
- 場所・住所・一覧表示名・場所メモの保存
- 名前・性別・メモの保存
- 最終訪問日と会えた時間帯の保存
- 訪問履歴の追加・編集・削除（時間帯とは別に訪問件数を入力可能、設定画面で表示オン・オフ切替）
- 不在履歴の追加・編集・削除
- タグ管理
- タグフィルター
- キーワード検索
- スワイプ削除
- ゴミ箱復元
- 現在地から住所・座標を取得
- 地図ピッカーから座標を保存
- Google Maps起動
- JSONバックアップ
- JSON復元
- PWAホーム画面追加

## データ保存

- メインストレージ：localStorage
- 起動後スナップショット：IndexedDB
- バックアップ：JSONエクスポート

主なlocalStorageキー:

- `vm_visits`
- `vm_trash`
- `vm_tags`
- `vm_backup_date`
- `vm_version`
- `vm_last_trash_purge`
- `vm_settings`（訪問件数入力欄の表示オン・オフなどの端末内設定。JSONバックアップの対象外）

既存のlocalStorageデータは、同じドメイン・同じパスで開く限り基本的に残ります。

## データ保護方針

このプロジェクトでは、次の変更を原則禁止します。

- `vm_visits` のキー名変更
- `vm_trash` のキー名変更
- `vm_tags` のキー名変更
- localStorageの初期化
- 保存済み訪問データの破壊的な形式変更
- JSONバックアップ形式の破壊的変更

## 起動高速化ホットフィックス 20260718-speed2

白画面が約5秒続く問題を軽減するため、次の処理を追加しています。

- Service Workerでアプリ本体を端末内へキャッシュ
- 2回目以降はキャッシュを優先して画面を表示
- 画面表示後、バックグラウンドで静的ファイルを更新
- `version.json`はキャッシュせず、従来の更新通知を維持
- Leaflet CDNのCSS・JavaScriptを2回目以降キャッシュ
- OpenStreetMap地図タイルとNominatim住所検索結果はキャッシュしない
- `vm_visits`、`vm_trash`、`vm_tags`を起動中に何度もJSON解析しない
- localStorageのキーとJSONバックアップ形式は変更しない
- アプリ表示バージョンは`1.0.11`のまま維持するホットフィックス

この更新の効果は、Service Workerが新しいキャッシュを作成した後の2回目以降の起動で最も現れます。

## これまでの起動高速化

- 起動直後のIndexedDBスナップショットを遅延実行
- 起動直後のバックアップ通知更新を遅延実行
- ゴミ箱30日削除チェックを1日1回だけ実行
- 訪問一覧の初回描画を50件に制限
- `さらに表示` ボタンで50件ずつ追加表示
- 起動後に `version.json` を確認し、新版があれば更新通知を表示
- 「更新して再起動」ボタンでService Worker更新とバージョン付き再読み込みを実行
- 設定画面の「アプリを更新」は保険として残す
- localStorageの既存キーと保存形式は変更しない
- 既存データを削除・移行・初期化しない

## 今回の反映手順

1. 念のため、現在のアプリでJSONバックアップを保存する
2. ZIPを解凍する
3. ZIP内のファイルをGitHubリポジトリのルートへアップロードする
4. `sw.js`、`js/db.js`、4つのMarkdownファイルを上書きする
5. 変更していない`index.html`、`js/app.js`、`js/ui.js`、アイコンは削除しない
6. GitHub ActionsのDeploy完了を確認する
7. iPhoneのPWAを開く
8. 「最新版があります」が表示された場合は「更新して再起動」を押す
9. 表示されない場合は、設定画面の「アプリを更新」を1回押す
10. 一度PWAを閉じて再度開き、2回目以降の起動時間を確認する

## 修正時の注意

- 既存データを消さない
- localStorageキーを変えない
- iPhone Safariで動作確認する
- Service Workerの更新事故に注意する
- コードを変更した場合はMarkdownも更新する
- 大きなファイルをGitHubコネクタ経由だけで取得して修正しない
- 今後はGitHubからリポジトリ一式ZIPをダウンロードしてから修正する

## 住所手入力時のGoogleマップ連携

- 現在地または地図から取得した有効な座標がある場合は、座標を優先してGoogleマップを開きます。
- 住所を手入力した場合は座標をクリアし、入力された住所文字列をそのままGoogleマップへ渡します。
- `岸谷4-4-4` のような短縮住所はGoogleマップ側の検索・推測に任せます。
- 空欄座標および誤って保存された `0,0` は有効な座標として扱いません。

## iPhoneでの外部地図・バックアップ保存

- Googleマップは新しい一時Safari画面を作らず、現在のPWA画面から起動します。
- Googleマップから戻った際に、空のブラウザ画面が残る現象を抑えます。
- iPhoneではバックアップJSONをiOS共有シートから保存します。
- 共有シートの「ファイルに保存」からiCloud DriveまたはこのiPhone内を選択できます。
- ファイル共有非対応環境では従来のダウンロード方式へ切り替えます。
- 共有をキャンセルした場合はバックアップ実施日を更新しません。
