Visit Manager v2 修正版アップロード対象

このZIPの中身を、GitHubの hipchin/visit-manager-v2 リポジトリへ同じパスで上書きしてください。

上書きするファイル:
- index.html
- sw.js
- css/style.css
- js/db.js
- js/ui.js
- js/app.js

変更内容:
1. トップページの訪問一覧カードを左スワイプで削除できるように変更
2. 二回目以降の訪問履歴を編集・削除できるように変更
3. タグを編集できるように変更
4. 訪問履歴・不在履歴の記録ボタンだけで既存レコードへ即保存されるように変更
5. 詳細画面の保存ボタンを下部に固定表示し、履歴が増えても隠れにくいように変更

アップロード後:
- GitHub Pagesの反映を待ってから、アプリの設定画面で「アプリを更新」を押してください。
- それでも旧表示なら、iPhone Safariでページを再読み込みしてください。
- 既存データは localStorage に残る設計なので、通常は消えません。ただし作業前にバックアップを取ることを強く推奨します。
