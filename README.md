# 訪問管理アプリ

飛び込み営業・訪問先管理用のPWAアプリです。

## ファイル構成

```text
visit-manager/
├── index.html
├── manifest.json
├── sw.js
├── css/
│   └── style.css
├── js/
│   ├── db.js
│   ├── tags.js
│   ├── ui.js
│   └── app.js
├── icons/
│   ├── icon-192.png
│   └── icon-512.png
└── .github/
    └── workflows/
        └── deploy.yml
```

## 反映手順

1. ZIPを解凍する
2. GitHubリポジトリのルートに中身をそのままアップロードする
3. 既存ファイルは上書きする
4. GitHub ActionsのDeployが完了するまで待つ
5. PWAを一度完全に閉じる
6. Safariで公開URLを `?v=20260709-speed1` 付きで開く
7. 画面が開いたら、設定 → アプリを更新を押す
8. ホーム画面のPWAを開き直す

## 今回の修正点

- 起動直後のIndexedDBスナップショットを遅延実行に変更
- 起動直後のバックアップ通知更新を遅延実行に変更
- ゴミ箱30日削除チェックを1日1回だけ実行する方式に変更
- 訪問一覧の初回描画を50件に制限
- 「さらに表示」ボタンで50件ずつ追加表示
- `localStorage` の既存キーと保存形式は変更なし
- 既存データを削除・移行・初期化しない方針を維持
- アプリ内部バージョンを `1.0.8` に更新

## データ保存

- メインストレージ：localStorage
- 起動後スナップショット：IndexedDB
- バックアップ：JSONエクスポート

既存のlocalStorageデータは、同じドメイン・同じパスで開く限り基本的に残ります。

## データ保護方針

今回の高速化では、以下を行っていません。

- `vm_visits` のキー名変更
- `vm_trash` のキー名変更
- `vm_tags` のキー名変更
- localStorageの初期化
- 保存済み訪問データの形式変更
- JSONバックアップ形式の破壊的変更

## 注意

`index.html` の読み込みバージョンパラメータが古い場合、ブラウザキャッシュにより古い `app.js` が読まれる可能性があります。その場合は公開URLを `?v=20260709-speed1` 付きで開き、設定からアプリ更新を実行してください。
