# DECISIONS

## 設計判断ログ

### データ保存

採用: - localStorage

理由: - 高速 - 実装が単純 - PWAと相性が良い

IndexedDB はスナップショット用途のみとする。

------------------------------------------------------------------------

### 地図

アプリ内: - Leaflet - OpenStreetMap

外部ナビ: - Google Maps

理由: - APIキー不要 - コスト不要 - ナビ品質はGoogle Mapsが高い

------------------------------------------------------------------------

### 座標優先

住所より座標を優先して保存・利用する。

理由: - マンションや新築地で位置ズレを防ぐため。

------------------------------------------------------------------------

### PWA

更新優先設計。

理由: - 古いキャッシュによる不具合を避けるため。

------------------------------------------------------------------------

### UI

スマートフォン片手操作を最優先とする。

------------------------------------------------------------------------

### 保守

ドキュメントをコードと同じ重要度で管理する。

コード変更時は関連ドキュメントを更新する。
